# Duck Harness × GLM-5.3-Flash 实验资料

面向 ChatGPT 阅读、讨论与代码审阅的**研究资料仓库**。实验资料截止日期：2026-09-04。

**执行前先读：[安全边界](SECURITY.md)与[加固运行入口](runtime/README.md)。** 2026-09-06 的审查发现冻结版本的 Python 隔离缺口。冻结快照与实验数据原样保留；需执行时从 `runtime/` 构建独立运行目录，采用 Linux 操作系统级隔离，不直接运行有已知缺陷的冻结入口。加固版尚未重跑游戏性能实验。

研究目标：让模型通过「假设 → 动作前预测 → 真实动作 → 下一状态校验 → 反例修订」理解 ARC-AGI-3 交互游戏，而不是仅输出貌似合理的规则解释。

## 先读结论

- 历史 GLM-5.3-Flash + Duck 在 LS20 有一次 **21 动作过首关、3.5714/100 分**的成功记录。这是单次结果，不是重复运行的均值。
- 新完成两轮开发评估，每轮 4 组 × 2 次，共 **16 次**。所有运行最多只完成第一关，**全游戏成功 0/16**。
- 第一轮检验「自动事实记录 × 位移门控」；第二轮检验「自动事实记录 × 动作前预测」。两轮的 combined 不是同一种处理。
- 第二轮 prediction 和 combined 各一次 3.5714、一次 0，均值均为 **1.7857**。出现高动作效率成功样本，但尚未证明稳定收益。
- 预测功能确实运行了；同时暴露了反馈漏显、旧转移误读、规则改名而非修复、低信息预测和共享时间预算引起的短截止问题。
- 第二轮结束后修复了工具反馈，完整测试 **113 项通过**。第二轮成绩属于**修复前冻结版本**，修复版尚未重新跑完整性能对照。
- 所有新增运行都是 LS20 开发重复评估，不是正式比赛提交，也没有跨游戏泛化证据。

## 核心结果

| 版本 | 组 | 首关成功 | 平均分 / 100 |
|---|---|---:|---:|
| 历史 | 单次成功运行 | 1/1 已记录正式运行 | 3.5714（单次） |
| 第一轮 | baseline | 1/2 | 0.4674 |
| 第一轮 | probe | 0/2 | 0 |
| 第一轮 | belief | 2/2 | 1.8948 |
| 第一轮 | combined（probe + belief） | 2/2 | 1.6470 |
| 第二轮 | baseline | 0/2 | 0 |
| 第二轮 | belief | 2/2 | 0.1324 |
| 第二轮 | prediction | 1/2 | 1.7857 |
| 第二轮 | combined（prediction + belief） | 1/2 | 1.7857 |

**跨行解释限制：**历史与新实验路由、配置、资源窗口等不同；两轮之间动作上限从 120 变为 1200、求解窗口从 19.5 分钟修正为 29 分钟。只有各轮内部是共享条件的探索性对照，每组 n=2。

## 离线核对

使用 Python 3 标准库，无需模型 API：

```bash
python tools/verify_archive.py
```

该命令核对已收录 JSON/JSONL、16 个正式槽位、benchmark 分数、动作总数和请求统计，不启动游戏，也不消耗模型 token。
