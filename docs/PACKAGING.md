# 发布范围与检查

本资料仓库按用户选择创建为私有。源实验仓库不变更远端，不把其整个工作区或 git 历史推送到新仓库。

2026-09-06 公开前审查后新增独立的 [加固运行入口](../runtime/README.md) 和 [安全边界](../SECURITY.md)。下面的资料打包记录仍描述原始归档；冻结源码、历史报告和数据不变。新的运行覆盖层不属于原实验处理，也不继承旧实验的性能结论。

## 收录

- 一个历史成功运行：benchmark、配置、事件；历史接口配置节选。
- 两轮全部16次正式运行：汇总、离线分析、benchmark、配置、真实事件和模型usage。
- 两轮冻结源码、第二轮实验后反馈修复和对应测试文件。
- 原始阶段报告、两轮协议、用户提供的背景分析；阶段报告和背景加纠正说明。
- 独立总览、证据地图、少量关键转录节选，保留节选原行号。

## 未收录

API密钥、环境文件、GitHub凭据、本机git元数据、虚拟环境、依赖缓存、完整模型转录、完整prompt日志、大型viewer衍生页面、未提供的原始ZIP。pilot的详细目录没有上传；其摘要来自实施报告，与正式16次分开。

## 转换

JSON/JSONL重新序列化；敏感键和值模式脱敏；本机源路径、Windows用户主目录和Linux用户主目录占位化。Markdown本机链接转到已收录相对文件，未收录目标改为文字说明。研究数值、动作、真实棋盘、预测和usage保留。

MANIFEST列出复制资料的仓库路径、源相对路径、字节数和文本是否转换；人工编写的入口文档和生成的节选/diff不在复制manifest中。打包统计见 [packaging-stats.json](packaging-stats.json)。不额外创建哈希体系。

## 验证

`python tools/verify_archive.py` 检查JSON/JSONL可解析、文档链接、manifest尺寸、常见凭据模式、16个终态槽位、动作总数、基于benchmark关卡累计成本重算的分数、usage请求/响应/错误计数和1800秒上限。

它不把新代码投入游戏，不消耗模型token；这次执行结果在仓库发布时核对。113项harness测试是先前反馈修复完成后的结果，不冒充本次重新运行。
